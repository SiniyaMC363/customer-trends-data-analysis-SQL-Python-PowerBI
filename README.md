🛒 Customer Shopping Behavior Analysis
📌 Overview

This project analyzes customer shopping behavior to uncover patterns, trends, and insights that help businesses understand purchasing habits and improve decision-making. The workflow covers data loading, cleaning, exploratory data analysis (EDA), SQL querying, and visualization through an interactive Power BI dashboard.

📂 Dataset

The dataset contains customer purchase information such as:

Customer details

Product categories

Purchase amounts

Transaction dates

Shopping frequency

Data is loaded and processed using Python for analysis and stored in a MySQL database for querying.

🛠️ Tools & Technologies

Python – Data loading, cleaning, and EDA

Libraries: Pandas, NumPy, Matplotlib, Seaborn

MySQL – Data storage and SQL queries

Power BI – Interactive dashboard and visualizations

Jupyter Notebook / VS Code – Development environment

🔄 Project Steps

Data Loading

Imported the dataset into Python using Pandas.

Data Cleaning

Handled missing values and duplicates

Corrected data types

Standardized column names and values

Exploratory Data Analysis (EDA)

Analyzed customer purchase patterns

Identified trends across categories and time

Visualized key metrics

SQL Analysis

Stored cleaned data in a MySQL server

Wrote SQL queries to extract business insights

Dashboard Creation

Built an interactive Power BI dashboard using SQL outputs

Reporting

Summarized findings and insights in a final report

📊 Power BI Dashboard

The dashboard provides:

Total sales and revenue trends

Customer purchase behavior insights

Category-wise and time-based analysis

Interactive filters for better exploration

📈 Results & Insights

Identified top-performing product categories

Observed customer spending patterns

Highlighted peak shopping periods

Provided data-driven insights to support business decisions

▶️ How to Run the Project

Clone the repository:

git clone <repository-link>


Install required Python libraries:

pip install -r requirements.txt


Run the Jupyter Notebook to perform EDA and data cleaning.

Load the cleaned dataset into the MySQL database.

Execute SQL queries for analysis.

Open the Power BI file and refresh data to view the dashboard.

📄 Conclusion

This project demonstrates an end-to-end data analytics workflow, combining Python, SQL, and Power BI to transform raw data into meaningful insights. It showcases practical skills relevant to real-world data analyst roles.
